# Comandos

## Poetry
- poetry install
- poetry add <paquete>
- poetry add <paquete> --group dev
- poetry remove <paquete>
- poetry run <comando>
- poetry shell
- poetry update

## Ruff
- poetry run ruff check .
- poetry run ruff check --fix .
- poetry run ruff format .

## Pyrefly
- poetry run pyrefly start
- poetry run pyrefly check
- poetry run pyrefly restart
- poetry run pyrefly stop
